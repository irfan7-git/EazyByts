How to Test Features

  1. Search: Use the search bar to find products by name, brand, or category
  2. Filters: Use the sidebar filters to narrow down products by price, brand, size
  3. Wishlist: Click the heart icon on any product to add to wishlist
  4. Quick View: Hover over products and click the eye icon for quick preview
  5. Cart: Add items and test promo codes like "OUTFITO20" for 20% off
  6. Views: Toggle between grid and list view using the top controls
  7. Sort: Use the sort dropdown to organize products
  8. Newsletter: Try subscribing with any email address
  9. Hero Slider: Watch auto-rotation or click navigation arrows
  10. Mobile: Try on mobile device for touch gestures and responsive design
